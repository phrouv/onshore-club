# Publish Test Results Snapshot

## Purpose

Create a self-contained, timestamped snapshot of the current E2E test run so that results can be shared, archived, and committed to the repository without polluting the working tree with raw `test-results/` and `playwright-report/` output.

The snapshot is placed in:
```
e2e-reboot/published-tests/<YYYY-MM-DD_HHMMSS>/
```

## What Gets Copied

| Source | Destination in snapshot | Notes |
|--------|------------------------|-------|
| `specifications/test-specification/release-20260120/*.csv` | `acceptance-criteria/` | All AC CSV files, filename prefixed with timestamp |
| `e2e-reboot/features/*.feature` | `features/` | All Gherkin feature files |
| `e2e-reboot/playwright-report/all/results.xml` | `execution-report/results.xml` | JUnit XML report |
| `e2e-reboot/playwright-report/all/index.html` | `execution-report/index.html` | HTML report entry point |
| `e2e-reboot/playwright-report/all/data/` | `execution-report/data/` | Report assets (JS/JSON) |

> `test-results/` (individual trace/video/screenshot artefacts) is **not** copied by default — they are large binary files. Include them only if explicitly requested.

---

## Steps to Execute

### Step 1 — Generate the timestamp

```bash
TS=$(date +"%Y-%m-%d_%H%M%S")
SNAPSHOT_DIR="e2e-reboot/published-tests/${TS}"
echo "Snapshot directory: ${SNAPSHOT_DIR}"
```

### Step 2 — Create the directory structure

```bash
mkdir -p "${SNAPSHOT_DIR}/acceptance-criteria"
mkdir -p "${SNAPSHOT_DIR}/features"
mkdir -p "${SNAPSHOT_DIR}/execution-report/data"
```

### Step 3 — Copy acceptance-criteria CSVs (timestamped filename)

```bash
for f in specifications/test-specification/release-20260120/*.csv; do
  base=$(basename "$f" .csv)
  cp "$f" "${SNAPSHOT_DIR}/acceptance-criteria/${base}_${TS}.csv"
done
echo "CSVs copied."
```

### Step 4 — Copy feature files

```bash
cp e2e-reboot/features/*.feature "${SNAPSHOT_DIR}/features/"
echo "Feature files copied."
```

### Step 5 — Copy Playwright execution report

```bash
# HTML report
cp e2e-reboot/playwright-report/all/index.html "${SNAPSHOT_DIR}/execution-report/" 2>/dev/null || echo "WARN: index.html not found — run tests first"
# JUnit XML
cp e2e-reboot/playwright-report/all/results.xml "${SNAPSHOT_DIR}/execution-report/" 2>/dev/null || echo "WARN: results.xml not found — run tests first"
# Report data assets
cp -r e2e-reboot/playwright-report/all/data/. "${SNAPSHOT_DIR}/execution-report/data/" 2>/dev/null || echo "WARN: data/ not found"
echo "Execution report copied."
```

### Step 6 — Write a snapshot manifest

Create a file `${SNAPSHOT_DIR}/SNAPSHOT.md` with the following content (fill in the actual values):

```markdown
# Test Results Snapshot

| Field | Value |
|-------|-------|
| Timestamp | <TS value from Step 1> |
| Branch | <output of `git branch --show-current`> |
| Commit | <output of `git rev-parse --short HEAD`> |
| Generated by | publish-test-results.prompt.md |

## Contents

- `acceptance-criteria/` — AC CSV files from `specifications/test-specification/release-20260120/`
- `features/` — Gherkin `.feature` files from `e2e-reboot/features/`
- `execution-report/` — Playwright HTML + JUnit XML report

## Test Run Summary

Paste the summary from the last test run here (pass/fail/skip counts per suite).
```

To fill the branch and commit automatically:

```bash
BRANCH=$(git branch --show-current)
COMMIT=$(git rev-parse --short HEAD)
```

### Step 7 — Confirm

List the snapshot directory and confirm the files are present:

```bash
find "${SNAPSHOT_DIR}" -type f | sort
```

## Full One-Shot Script

Run all steps above in one shot from the **repository root**:

```bash
#!/usr/bin/env bash
set -euo pipefail

TS=$(date +"%Y-%m-%d_%H%M%S")
SNAPSHOT_DIR="e2e-reboot/published-tests/${TS}"
BRANCH=$(git branch --show-current 2>/dev/null || echo "unknown")
COMMIT=$(git rev-parse --short HEAD 2>/dev/null || echo "unknown")

echo "==> Creating snapshot: ${SNAPSHOT_DIR}"

mkdir -p "${SNAPSHOT_DIR}/acceptance-criteria"
mkdir -p "${SNAPSHOT_DIR}/features"
mkdir -p "${SNAPSHOT_DIR}/execution-report/data"

# CSVs
for f in specifications/test-specification/release-20260120/*.csv; do
  base=$(basename "$f" .csv)
  cp "$f" "${SNAPSHOT_DIR}/acceptance-criteria/${base}_${TS}.csv"
done

# Feature files
cp e2e-reboot/features/*.feature "${SNAPSHOT_DIR}/features/"

# Playwright report
cp e2e-reboot/playwright-report/all/index.html "${SNAPSHOT_DIR}/execution-report/" 2>/dev/null || true
cp e2e-reboot/playwright-report/all/results.xml "${SNAPSHOT_DIR}/execution-report/" 2>/dev/null || true
cp -r e2e-reboot/playwright-report/all/data/. "${SNAPSHOT_DIR}/execution-report/data/" 2>/dev/null || true

# Manifest
cat > "${SNAPSHOT_DIR}/SNAPSHOT.md" <<EOF
# Test Results Snapshot

| Field | Value |
|-------|-------|
| Timestamp | ${TS} |
| Branch | ${BRANCH} |
| Commit | ${COMMIT} |
| Generated by | publish-test-results.prompt.md |

## Contents

- \`acceptance-criteria/\` — AC CSV files (timestamped) from \`specifications/test-specification/release-20260120/\`
- \`features/\` — Gherkin \`.feature\` files from \`e2e-reboot/features/\`
- \`execution-report/\` — Playwright HTML + JUnit XML report

## Files

$(find "${SNAPSHOT_DIR}" -type f | sed "s|${SNAPSHOT_DIR}/||" | sort)
EOF

echo "==> Snapshot complete."
find "${SNAPSHOT_DIR}" -type f | sort
```

Save this script as `scripts/publish-test-results.sh` and run it from the repository root when needed:

```bash
bash scripts/publish-test-results.sh
```

---

## After Publishing

- Commit the snapshot directory: `git add e2e-reboot/published-tests/<timestamp>/ && git commit`
- `playwright-report/` and `test-results/` remain gitignored and are **not committed**
- Published snapshots are the permanent record of test runs
